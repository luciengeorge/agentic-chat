# Tour

Before you build any layer, you run the whole app and watch one question move through it. Every later step changes one piece of this system, so it helps to see the pieces first.

Two steps, neither graded:

1. **Run the app.** Start the database, the app and the stand-in file store, sign in, and check that the parts talk to each other.
2. **Follow a question.** Trace one question from the route that receives it to the answer, then watch one workflow run step by step.
