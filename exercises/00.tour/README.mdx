# Tour

Before you build any layer, you run the whole app and watch one request move through it. Every later step changes one piece of this system, so it helps to see the pieces first.

Two steps, neither graded:

1. **Run the stack.** Start every service, sign in, and check that the parts talk to each other.
2. **Follow a request through Grafana.** Read one request's trace and see which services it touched and how long each took.
